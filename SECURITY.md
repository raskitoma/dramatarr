# Security Policy

## Supported Versions

Only the latest commit on `main` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Dramatarr, please do **NOT** open a public issue.

Instead, please report vulnerabilities by opening a private report through **GitHub Security Advisory** on the repository page:
1. Navigate to the repository on GitHub.
2. Click on the **Security** tab.
3. Select **Advisories** and click **Report a vulnerability**.

Alternatively, send an email to the repository owner.

Please include:
- A description of the issue and potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the vulnerability.
- Any suggested mitigations.

We will acknowledge receipt of your report within 48 hours and work with you on a coordinated disclosure timeline.
