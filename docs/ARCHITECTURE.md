# dramatarr — Architecture Contract

Self-hosted, invite-only household drama/series library. Runs as a Docker app with the
media library on a NAS mount.

**This document is the contract.** Every module is implemented against it. If an
implementation detail is not specified here, prefer the simplest thing that satisfies the
stated behaviour, and do not change any signature, route, table, or field name defined below.

---

## 0. Scope and non-goals

**In scope**

- Two roles: `admin` and `viewer`. Admins do everything viewers do, plus library/job/user/settings management.
- Enrollment is **invite-only**, by email. There is no public signup.
- Authentication is **passkeys (WebAuthn)** first, with an email magic-link fallback.
- The media library is a NAS mount that dramatarr treats as **read-only everywhere except one
  place**: `app/services/renamer.py`, which renames a matched series' files so their names mean
  something. That is the only writer, it is gated behind an admin action with a preview, and it
  renames in place — it never moves a file between directories and never overwrites one. The
  scanner, the streamer, the metadata jobs and the deletion routes are all still read-only.
- A **strictly serialized job queue** (concurrency exactly 1) drives scanning, metadata,
  image caching and thumbnail generation, with live progress.
- Streaming is direct-play with HTTP range requests, plus on-demand subtitle extraction.
- Per-user watch state: watched / in-progress / resume position / percent / rewatch.
- Multilingual search over native titles, romanizations and alternate titles.
- Full UI localization (es, en shipped) and auto/light/dark theming.

**Explicit non-goals**

- No scraping of, or downloading from, third-party streaming sites. The ingestion layer is a
  provider interface; the only shipped provider reads the local mount. A `remote_import`
  job type exists but is inert unless an admin configures a base URL for a source they
  operate, and it only accepts a direct file URL — it does not crawl.
- No transcoding in v1. Files that the browser cannot direct-play are surfaced as such.
  `MediaFile.direct_play_ok` records the verdict; the transcode path is a later addition.
- No multi-tenant separation beyond the single household.

## 1. Runtime topology

```
docker compose
├── api        FastAPI (uvicorn), single process, hosts the queue worker in-process
│              volumes:  /library (rw, NAS)   /data (rw, sqlite + caches)
└── web        nginx serving the built React SPA, proxies /api → api:8000
```

Single API process is deliberate: the queue must be serialized and an in-process asyncio
worker with `concurrency=1` is the simplest correct implementation. Do not add a second
worker container.

**Paths inside the api container**

| Path                  | Mode | Contents                                             |
| --------------------- | ---- | ---------------------------------------------------- |
| `/library`            | rw   | The NAS media library. Written by exactly one thing — the renamer (§8). |
| `/data/dramatarr.db`   | rw   | SQLite (WAL)                                         |
| `/data/images/`       | rw   | Cached posters/backdrops/stills from TMDB            |
| `/data/thumbs/`       | rw   | Generated scrubbing sprites                          |
| `/data/subs/`         | rw   | Subtitle tracks extracted to WebVTT                  |

## 2. Conventions

- **Python**: 3.12+ target, `async def` for all I/O paths. SQLAlchemy 2.0 declarative with
  `Mapped[...]` / `mapped_column`. Pydantic v2. Line length 100. Full type annotations.
- **IDs**: every table's PK is `id: str`, a UUIDv4 hex string generated by `app.utils.ids.new_id()`.
  Not integers — it keeps API responses stable and avoids enumeration.
- **Timestamps**: all `datetime` columns are timezone-aware UTC, named `*_at`. Serialize as
  ISO-8601 with `Z`. Helper: `app.utils.time.utcnow()`.
- **Enums**: Python `enum.StrEnum`, stored as `String` (not native DB enums — SQLite).
- **Naming**: tables plural snake_case; API JSON fields camelCase via a shared Pydantic
  `alias_generator`; Python attributes snake_case.
- **Errors**: raise `app.errors.AppError(code, message, status)`. A single exception handler
  renders `{"error": {"code": "...", "message": "...", "details": {...}}}`. Error codes are
  stable SCREAMING_SNAKE strings; the frontend maps them to localized strings.
- **Frontend**: React 19, TypeScript strict, Vite, TanStack Query for server state, wouter for
  routing, react-i18next. No CSS framework — plain CSS modules over design tokens (§9).
- **No secrets in the repo.** Everything configurable comes from env (§3).

| `DRAMATARR_DATABASE_URL`       | `sqlite+aiosqlite:////data/dramatarr.db` |                             |
| `DRAMATARR_LIBRARY_ROOT`       | `/library`               | The NAS mount. Written only by the renamer (§8).    |
| `DRAMATARR_DATA_DIR`           | `/data`                  |                                                     |
| `DRAMATARR_PUBLIC_URL`         | `http://localhost:8080`  | Used to build links in emails                       |
| `DRAMATARR_WEBAUTHN_RP_ID`     | `localhost`              | Must match the site's registrable domain            |
| `DRAMATARR_WEBAUTHN_RP_NAME`   | `dramatarr`               |                                                     |

| `DRAMATARR_DEFAULT_LOCALE`     | `es`                     |                                                     |
| `DRAMATARR_BOOTSTRAP_ADMIN_EMAIL` | none                  | On first boot, seeds an admin + prints an enrollment link |
| `DRAMATARR_LOG_LEVEL`          | `INFO`                   |                                                     |

Runtime-mutable settings live in the `settings` table (§4) and are edited by admins in the UI,
**not** in env: TMDB key, SMTP config, site name, scan schedule, source base URL. Access them
through `app.services.settings.SettingsService`, which caches and invalidates on write.

Settings table keys (typed accessors required):

```
tmdb.api_key            str   secret, write-only over the API
tmdb.language           str   default "es-ES"
smtp.host smtp.port smtp.username smtp.password smtp.from_email smtp.from_name smtp.use_tls
site.name               str   default "dramatarr"
site.default_locale     str
library.scan_cron       str   default "0 4 * * *"  (empty disables)
library.source_base_url str   default ""  — the configurable source origin; inert when empty
auth.magic_link_enabled bool  default true

images.search.provider    str   ""  |  "searxng"  |  "google_cse"   — "" disables the feature
images.search.api_key     str   secret; required by google_cse, optional for searxng
images.search.base_url    str   searxng only, e.g. http://10.0.50.30:8080
images.search.engines     str   searxng only; comma-separated engine names, "" = the instance's
images.search.safe_search      searxng's 0/1/2 *or* the name the UI writes ("off"|"moderate"
                               |"strict"); read through images.parse_safe_search, default 1
images.search.language    str   default "" = the instance's default
images.search.timeout     int   seconds, default 15
images.search.cse_id      str   google_cse only
```

`*.password` / `*.api_key` are redacted to `"__SET__"` or `null` on read. Never returned.

**Web image search** is an optional *supplement* to the artwork picker; TMDB's gallery, a
pasted URL and a file upload work without it. The recommended provider is the household's own
**SearXNG** (`GET {base_url}/search?q=…&format=json&categories=images`) — no third-party key,
no quota, and the query never leaves the network. Google Custom Search remains implemented and
selectable. Two properties of this feature are load-bearing:

- **SearXNG ships with the JSON API disabled.** An instance in that state answers `format=json`
  with HTML or a 403. That is detected and reported as `SEARXNG_JSON_DISABLED`, whose message
  names the fix — add `json` to `search.formats` in the instance's `settings.yml` and restart.
  `POST /api/admin/settings/test-search` exists to surface it before the admin hits it in the
  picker.
- **The configured `base_url` is trusted; the `img_src` URLs in the results are not.** A
  self-hosted instance normally lives on a private address, so requests to `base_url` must not
  go through the private-address guard. Result images come from the open internet by way of a
  search engine, so downloading one keeps going through the full artwork path: http(s) only,
  private/loopback/link-local refused, redirects re-checked, size capped, re-encoded through
  ffmpeg. One rule for both would either break the feature or open a hole.
- **`images.search.api_key` is one slot serving two providers**, so changing
  `images.search.provider` clears it unless the same `PUT /api/admin/settings` supplies a new
  one. Otherwise a Google API key would go out as `Authorization: Bearer …` to the household's
  SearXNG instance. `cse_id`, `base_url` and the engine list are kept — they are not
  credentials, and switching back should not mean retyping everything.

## 4. Data model

All tables carry `id` (str PK). Relationships use `ondelete` as noted. Indexes listed are required.

### Identity

**`users`**
`id`, `email` (unique, citext-lower), `display_name`, `role` (`admin|viewer`),
`is_active` (bool, default true), `is_protected` (bool, default false — see below),
`locale` (default from settings), `theme` (`auto|light|dark`,
default `auto`), `preferred_audio_lang` (nullable), `preferred_subtitle_lang` (nullable),
`avatar_color` (hex, assigned at creation), `created_at`, `last_login_at` (nullable).

> `is_protected` (migration `0004`) marks the **founding account** — the one the household was
> bootstrapped with, and its recovery path of last resort. While it is set, every mutation of
> that row through `/api/admin/users` is refused with `PROTECTED_ACCOUNT`, so no admin can
> demote, deactivate, rename or delete it from the web UI, by accident or with a stolen admin
> session. The flag is deliberately not writable through any API: it moves only from a shell,
> with `python -m app.cli protect|unprotect`. Self-service through `/api/me` is unaffected, and
> the last-admin guard still applies to everyone else.

**`credentials`** — one row per registered passkey. `user_id` → users ON DELETE CASCADE.
`credential_id` (bytes, unique, indexed), `public_key` (bytes), `sign_count` (int),
`transports` (JSON list[str]), `aaguid` (str, nullable), `nickname` (str — user-editable label,
defaults to a guess from AAGUID/UA), `backed_up` (bool), `created_at`, `last_used_at` (nullable).

**`invites`** — `email`, `role`, `token_hash` (sha256 of the raw token, unique), `created_by_id`
→ users ON DELETE SET NULL, `expires_at`, `accepted_at` (nullable), `accepted_user_id`
(nullable), `created_at`. Raw token is shown once at creation and mailed; never stored.

**`auth_sessions`** — `user_id` ON DELETE CASCADE, `token_hash` (unique, indexed),
`user_agent`, `ip`, `created_at`, `expires_at`, `last_seen_at`, `revoked_at` (nullable).

**`magic_links`** — `user_id` ON DELETE CASCADE, `token_hash` (unique), `expires_at` (10 min),
`consumed_at` (nullable), `created_at`.

**`webauthn_challenges`** — short-lived server-side challenge store.
`challenge` (bytes), `kind` (`registration|authentication`), `user_id` (nullable — absent for
discoverable-credential login), `invite_id` (nullable), `expires_at` (5 min), `created_at`.

### Library

**`series`**
`slug` (unique, indexed — url-safe, derived from canonical title + disambiguator),
`title` (canonical display title), `sort_title` (normalized for ordering),
`original_title` (nullable), `original_language` (BCP-47, nullable),
`overview` (text, nullable), `year` (int, nullable),
`status` (`ongoing|completed|unknown`, default `unknown`),
`content_rating` (nullable), `genres` (JSON list[str], default []),
`network` (nullable), `tmdb_id` (int, nullable, indexed), `imdb_id` (nullable),
`poster_path` (nullable — path under `/data/images`), `backdrop_path` (nullable),
`declared_episode_count` (int, nullable — from metadata, may exceed files present),
`library_path` (str — folder relative to `LIBRARY_ROOT`, unique),
`metadata_locked` (bool, default false — when true, metadata jobs never overwrite),
`added_at`, `updated_at`.

> `metadata_locked` is the mechanism behind "the admin can edit metadata, but the program
> fetches it when it can". Any admin edit to a metadata field sets it to true for that series.

**`series_titles`** — powers multilingual search. `series_id` ON DELETE CASCADE,
`language` (BCP-47 or `""` for language-neutral), `title`, `kind`
(`official|native|romanization|alternate|acronym`), `source` (`tmdb|manual|filename`),
`normalized` (str, indexed — output of §7 normalization), `created_at`.
Unique on (`series_id`, `language`, `title`).

**`series_translations`** — `series_id` ON DELETE CASCADE, `language`, `overview` (nullable),
`tagline` (nullable). Unique on (`series_id`, `language`).

**`episodes`** — `series_id` ON DELETE CASCADE, `season_number` (int, default 1),
`episode_number` (int), `absolute_number` (int, nullable),
`title` (nullable), `overview` (nullable), `air_date` (date, nullable),
`runtime_seconds` (int, nullable — declared; the real one comes from the media file),
`tmdb_id` (nullable), `still_path` (nullable), `metadata_locked` (bool, default false),
`added_at`, `updated_at`. Unique on (`series_id`, `season_number`, `episode_number`).
Indexed on (`series_id`, `absolute_number`).

An episode row may exist with **no** media file — that is how "declared but not available"
is represented. `Episode.is_available` is a derived property: a present media file exists.

**`episode_titles`** — same shape as `series_titles`, keyed by `episode_id`.

**`media_files`** — `episode_id` ON DELETE CASCADE (nullable → unmatched file, kept for the
admin's "unmatched" view), `path` (unique, relative to `LIBRARY_ROOT`), `size_bytes`,
`mtime` (float), `container`, `video_codec` (nullable), `audio_codec` (nullable),
`width`, `height`, `duration_seconds` (float, nullable), `bitrate` (nullable),
`direct_play_ok` (bool — heuristic from §8), `status` (`present|missing|error`),
`scan_error` (nullable), `first_seen_at`, `scanned_at`.

**`audio_tracks`** — `media_file_id` ON DELETE CASCADE, `stream_index`, `language` (nullable),
`title` (nullable), `codec`, `channels`, `is_default`.

**`subtitle_tracks`** — `media_file_id` ON DELETE CASCADE, `stream_index` (nullable — null for
sidecar files), `language` (nullable), `title` (nullable), `codec`, `is_default`, `is_forced`,
`sidecar_path` (nullable, relative to `LIBRARY_ROOT`), `extracted_path` (nullable, under
`/data/subs`, set lazily on first request).

### Watch state

**`watch_progress`** — unique on (`user_id`, `episode_id`), both ON DELETE CASCADE.
`position_seconds` (float), `duration_seconds` (float),
`percent` (float 0–100, maintained on write),
`completed` (bool), `play_count` (int, default 0),
`first_played_at`, `last_played_at`.

Rules, implemented in `WatchService` and relied on by the UI:
- An episode is **completed** when `percent >= 90` **or** the remaining time is `< 120s`.
- On reaching completed, `play_count` increments once per viewing (not per progress ping).
- Starting an episode that is already `completed` begins a **rewatch**: `completed` resets to
  false and `position_seconds` to 0, `play_count` is preserved.
- Resume is suppressed when `position_seconds < 15` or the episode is completed.

**`play_events`** — append-only, for "continue watching" ordering and nothing else.
`user_id`, `episode_id`, `series_id` (denormalized), `at`, `position_seconds`.

### Jobs

**`jobs`** — `type` (§6), `status` (`queued|running|succeeded|failed|canceled`),
`priority` (int, default 100 — lower runs first), `payload` (JSON),
`progress_percent` (float 0–100), `progress_message` (str),
`attempts` (int), `max_attempts` (int, default 3), `error` (nullable),
`series_id` (nullable, for display), `episode_id` (nullable),
`created_by_id` (nullable), `created_at`, `started_at`, `finished_at`.
Indexed on (`status`, `priority`, `created_at`).

Queue is paused/resumed globally via the `queue.paused` setting; a paused queue finishes the
running job and then stops claiming.

**`job_logs`** — `job_id` ON DELETE CASCADE, `at`, `level` (`debug|info|warning|error`), `message`.

**`audit_log`** — `user_id` (nullable), `action`, `entity_type`, `entity_id`, `detail` (JSON), `at`.

**`settings`** — `key` (PK, str), `value` (JSON), `updated_at`, `updated_by_id` (nullable).

### Requests (the wishlist)

**`series_requests`** — what a member asked the household to add. A note for a person, not an
instruction for a program: **no worker reads this table and no job type consumes it.**

`user_id` ON DELETE **CASCADE** (a member's wishlist belongs to the member),
`title`, `year` (nullable),
`poster_url` (nullable, remote, host-allowlisted on write — see below),
`source_url` (nullable), `source_domain` (derived server-side from `source_url`, never taken
from the client),
`tmdb_id` / `imdb_id` (nullable) plus `external_ids` (JSON: mydramalist, dramaboxdb, wikipedia,
wikidata),
`dedupe_key`, `note` (nullable),
`status` (`pending|approved|fulfilled|declined`), `admin_note` (nullable),
`series_id` ON DELETE **SET NULL**, `resolved_by_user_id` ON DELETE **SET NULL**, `resolved_at`,
`created_at`, `updated_at`.

Unique on (`user_id`, `dedupe_key`); indexed on `user_id`, `status`, `series_id`, `dedupe_key`
and (`status`, `created_at`).

Three rules carry the feature:

- **`dedupe_key` is identity.** Strongest identifier first — `tmdb:{kind}:{id}`, then imdb,
  mydramalist, dramaboxdb, wikidata, wikipedia — falling back to `title:{normalized}:{year}`
  through the same `normalize()` the multilingual index uses. The TMDB *kind* is part of the
  key because `/movie/550` and `/tv/550` are different titles. This is what makes "you already
  asked for this" answerable, what the unique constraint means, and what lets the admin see
  that three people asked for one drama under three spellings.
- **`poster_url` is allowlisted to TMDB's image CDN and dropped otherwise.** The column is
  rendered in an `<img>` in the *admin's* browser, so an arbitrary URL there is a beacon. A
  poster that fails the check is discarded and the request still succeeds — the ask is the
  point, the picture is decoration.
- **`SET NULL`, not cascade, on `series_id`.** Deleting a series must not erase the record
  that somebody asked for it.

## 5. HTTP API

Base path `/api`. JSON in/out, camelCase. Auth is a `dramatarr_session` httpOnly, SameSite=Lax,
Secure-when-https cookie holding an opaque 32-byte token; the DB stores only its sha256.

Every route below is annotated with its required role: `public`, `user`, `admin`.

### Auth — `/api/auth`

| Method | Path                              | Role   | Purpose |
| ------ | --------------------------------- | ------ | ------- |
| GET    | `/session`                        | public | Current user or `{"user": null}`. Never 401s. |
| POST   | `/logout`                         | user   | Revokes the current session. |
| POST   | `/passkey/login/begin`            | public | → WebAuthn `PublicKeyCredentialRequestOptions`. Discoverable creds: no email needed. |
| POST   | `/passkey/login/complete`         | public | Verifies assertion, sets cookie. |
| GET    | `/passkeys`                       | user   | List own credentials. |
| POST   | `/passkey/register/begin`         | user   | Add another passkey to the signed-in account. |
| POST   | `/passkey/register/complete`      | user   | |
| PATCH  | `/passkeys/{id}`                  | user   | Rename. Own credentials only. |
| DELETE | `/passkeys/{id}`                  | user   | Refuse if it is the last credential **and** magic-link is disabled. |
| GET    | `/invite/{token}`                 | public | Validate token → `{email, role, siteName}` or an error code. |
| POST   | `/invite/{token}/begin`           | public | WebAuthn registration options for a brand-new user. |
| POST   | `/invite/{token}/complete`        | public | Creates the user, consumes the invite, signs in. |
| POST   | `/magic-link/request`             | public | Always 204 regardless of whether the email exists. Rate-limited. |
| POST   | `/magic-link/consume`             | public | Body `{token}` → sets cookie. |

User verification is `preferred`; resident keys `required` for the login-without-email flow.

### Streaming — `/api/stream`

| Method | Path                                  | Role | Purpose |
| ------ | ------------------------------------- | ---- | ------- |
| GET    | `/{episodeId}`                        | user | The media file. **Must** honour `Range` and reply 206 with `Accept-Ranges: bytes`, correct `Content-Range`/`Content-Length`. 404 when unavailable. |
| GET    | `/{episodeId}/subtitles/{trackId}.vtt`| user | WebVTT. Extracts/converts on first request via ffmpeg, caches under `/data/subs`, then serves from cache. |
| GET    | `/{episodeId}/thumbnails.vtt`         | user | Scrubbing sprite cues, 404 if not generated. |
| GET    | `/images/{kind}/{name}`               | user | Cached poster/backdrop/still. Long cache headers. |

Range handling is the single most failure-prone piece: parse only `bytes=start-end`,
clamp `end` to `size-1`, treat a suffix range (`bytes=-N`) correctly, and return 416 with
`Content-Range: bytes */size` on an unsatisfiable range.

### Requests — `/api/requests`

The member's half of the wishlist. The admin's half is under `/api/admin` and the split is by
**audience, not by table**: only the admin routes ever say *who* asked, and `require_admin`
sits on that router, so "another member can never see who requested what" is a property of
where the route lives rather than of a decorator someone has to remember.

| Method | Path             | Role | Purpose |
| ------ | ---------------- | ---- | ------- |
| GET    | `/search`        | user | `?q=&limit=`. Asks TMDB and the household's SearXNG **concurrently** and merges them: TMDB rows become cards with posters; a web result whose URL carries a TMDB id is promoted into a record by looking that id up (bounded, best-effort); anything else stays a link with its domain printed on it. Marks each card `inLibrary` (by tmdb id, else normalized title against `series_titles`) and `requested` (this caller only). Returns `{query, providers, configured, results}` — an unconfigured provider is a state, not an error. |
| GET    | ``               | user | This caller's own requests. Never anybody else's — scoped in SQL, not filtered afterwards. |
| POST   | ``               | user | Body `{title, year, posterUrl, sourceUrl, ids, note}`. `ids` may be empty: a title typed by hand is a valid request and is the only path that works with no provider configured. Refuses `REQUEST_ALREADY_IN_LIBRARY` (409, re-checked at write time, not trusted from the client); a repeat returns the existing row with `alreadyExisted` rather than writing a second. |
| DELETE | `/{id}`          | user | Withdraw your own, in any state. Another member's id answers `REQUEST_NOT_FOUND`, not 403 — whether a request exists is itself private. |

**Concurrency note.** `search` resolves both provider configurations off the session
*sequentially*, races only the two network calls, then goes back to sequential for every
database read. An `AsyncSession` is not safe for concurrent use, so gathering the two provider
calls with the session still in hand corrupts both — quietly, surfacing as an unrelated error
elsewhere. `discovery.discover_with()` exists to make that split possible.

## 6. Job queue

`app/workers/queue.py` owns a single asyncio task started in the FastAPI lifespan.

```python
class JobHandler(Protocol):
    type: JobType
    async def run(self, ctx: JobContext) -> None: ...

class JobContext:
    job: Job
    session: AsyncSession
    async def progress(self, percent: float, message: str) -> None: ...
    async def log(self, level: str, message: str) -> None: ...
    def cancelled(self) -> bool: ...   # handlers must poll this in their loops
```

Loop: claim the oldest `queued` job by (`priority`, `created_at`) inside an immediate
transaction → `running` → dispatch to its handler → `succeeded` / `failed` (retry with
exponential backoff while `attempts < max_attempts`). Exactly one job runs at a time; this is
a hard requirement, not a tunable.

**Job types**

| Type               | Payload                        | Does |
| ------------------ | ------------------------------ | ---- |
| `library_scan`     | `{path?: str, full?: bool}`    | Walk the mount, diff against `media_files`, ffprobe new/changed files, parse names (§8), create/attach series+episodes, mark vanished files `missing`. Enqueues `metadata_refresh` for new series. |
| `metadata_refresh` | `{seriesId, tmdbId?}`          | TMDB lookup → titles (all languages), translations, episodes, image URLs. Skips any field on a `metadata_locked` row. Enqueues `image_cache`. |
| `image_cache`      | `{seriesId?, episodeId?}`      | Download poster/backdrop/stills into `/data/images`, store relative paths. |
| `thumbnail_sprite` | `{episodeId}`                  | ffmpeg sprite sheet + WebVTT cues into `/data/thumbs`. |
| `remote_import`    | `{url, seriesId, episodeNumber}` | Inert unless `library.source_base_url` is set and `url` is under it. Downloads one file to a staging dir. Not wired into the UI by default. |

**SSE** on `/api/admin/events`, `text/event-stream`, events named
`job.created | job.started | job.progress | job.finished | queue.state`, payload is the job JSON.
An in-memory pub/sub (`asyncio.Queue` per subscriber) is sufficient — single process. Send a
comment heartbeat every 25s so proxies don't drop the connection.

## 7. Multilingual search

Two cooperating pieces.

**Normalization** — `app/services/search/normalize.py`

```python
def normalize(text: str) -> str        # NFKC → casefold → strip diacritics → collapse ws/punct
def romanize(text: str) -> list[str]   # script-aware; may return several candidates
def search_keys(title: str) -> list[str]  # normalize(title) + romanize variants, deduped
```

`romanize` dispatches on detected script: Han → pinyin (with and without tone marks, plus the
initials acronym, e.g. 迷情 → `mi qing`, `miqing`, `mq`); Hangul → Revised Romanization;
Kana/Kanji → romaji; Cyrillic → ISO-9. Anything else falls through to a diacritic-stripped
form. Every generated variant is stored as its own `series_titles` row with
`kind='romanization'`, so the index is plain text and the query path stays simple.

Dependencies: `pypinyin`, `korean-romanizer`, `pykakasi`, `unidecode`. Each is wrapped in a
try/except at import; a missing optional dependency degrades that script to `unidecode` rather
than breaking startup.

**Index** — SQLite FTS5 external-content table `search_index(kind, ref_id, series_id, text)`
using the **trigram** tokenizer (`tokenize='trigram'`), which handles CJK and substring
matching uniformly. Rebuilt incrementally whenever a title row changes; a
`search_reindex` maintenance path rebuilds it wholesale.

Query path: normalize the query the same way → FTS5 MATCH → re-rank with `rapidfuzz`
`WRatio` against every stored variant of each candidate → group by series → return series with
their best-matching title and the field that matched, so the UI can show *why* it matched.
A query shorter than 3 characters falls back to a prefix `LIKE` on `normalized`.

Acceptance: searching `mi qing`, `miqing`, `迷情`, or a registered English title must all return
the same series.

## 8. Scanner

`app/services/scanner/`

Layout expected on the NAS (both supported):

```
/library/Series Name (2024)/Season 01/Series Name - S01E03 - Title.mkv
/library/Series Name/Series Name - 03.mp4
```

**Filename parsing** — `parse.py`, pure functions, heavily unit-tested. Recognize, in order:
`SxxEyy`, `Season x Episode y`, `x之y`/`第y集` (CJK episode markers), `- yy -`, `Eyy`,
`EPyy`, `[yy]`, and a bare trailing number. Extract year from `(2024)` or `[2024]`.
Strip release-group noise and quality tags before matching. When no season is found, assume 1.
Unparseable files still produce a `media_files` row with `episode_id = NULL` so the admin sees
them under "unmatched" — never silently dropped.

**Video extensions**: mkv, mp4, m4v, avi, mov, webm, ts, m2ts, wmv, flv.
**Sidecar subtitles**: srt, ass, ssa, vtt, sub — matched to a video by stem prefix, language
guessed from the trailing suffix (`.es.srt`, `.spa.srt`, `.pt-BR.srt`).

**Probing** — `probe.py` shells `ffprobe -v quiet -print_format json -show_format -show_streams`
with a timeout, into typed dataclasses. `direct_play_ok` is true when container ∈ {mp4, m4v,
webm} **or** (container == mkv **and** video codec ∈ {h264, vp8, vp9, av1} **and** audio codec ∈
{aac, mp3, opus, vorbis, flac}) — mkv is included because browsers commonly play it when the
codecs are right; the UI warns rather than blocks.

Change detection is `(size_bytes, mtime)`; unchanged files are not re-probed. The scan must be
incremental and interruptible — check `ctx.cancelled()` every file and report progress by
file count.

Never write to `LIBRARY_ROOT` **from the scanner, the streamer or the metadata jobs**. Open
files read-only. Resolve every path and verify it stays under `LIBRARY_ROOT` before opening
(path-traversal guard) — this applies to streaming too.

The one exception is `app/services/renamer.py`, and it earns it by being narrower than the rule
it breaks:

- **Rename in place.** The target's parent is taken from the source and never recomputed, so no
  code path here can relocate a file into another series' folder or anywhere else.
- **Never overwrite.** An existing target is a collision: the file is skipped, reported, and
  left alone. There is no flag to force it.
- **Both ends guarded.** Source and target go through `safe_media_path`, which resolves
  symlinks first, so neither a crafted series title nor a link out of the library can address
  anything outside the root.
- **Runs as a job.** `JobType.LIBRARY_RENAME`, so it is serialized against the scanner by the
  queue's concurrency of exactly one, and its per-file outcome lands in the job log.
- **The catalogue follows the disk, per file.** `media_files.path` is committed with each
  rename, so an interrupted run leaves the rows agreeing with what is actually there.

`GET /library/series/{id}/rename-plan` is the preview and writes nothing;
`POST /library/series/{id}/rename` enqueues the job. The worker re-plans rather than trusting
what the admin approved, because the filesystem is the authority on what is safe to do now.
